# Static demo and screenshots

## Scope

This is an interactive preview of the real web frontend, using synthetic fixtures and a demo-only API adapter. It does not run Python, source APIs, AI models or MySQL. Run status and logs are explicitly simulated. It is a project demonstration, not a commercial SaaS service or checkout site.

Open `demo/index.html` through a static HTTP server. Select the demo saved version, inspect schema/SQL, or open Saved jobs and simulate a run. SQL was generated by the existing Python generator during the build. Edited schemas and custom templates cannot be regenerated in the browser; the demo reports this limitation instead of returning mismatched SQL.

## Rebuild

From the repository root:

```sh
.venv/bin/python scripts/build_web_demo.py
python3 -m http.server 8766 --directory docs --bind 127.0.0.1
```

Open http://127.0.0.1:8766/ for the tour or http://127.0.0.1:8766/demo/ for the demo.

The build copies the real frontend into `docs/demo/` and generates an example definition with the existing schema/SQL functions. `demo.js` and `demo.css` provide the static adapter/banner and are maintained separately. Do not edit generated `app.js`, `app.css`, `i18n.js`, `fixture.js` or `index.html`; rebuild them. No local definitions, logs, environment variables or credentials are read into demo assets.

## Publish on GitHub Pages

GitHub Pages supports static HTML/CSS/JS and is available for public repositories on GitHub Free. It cannot host the Python ETL workers. Official references: [About Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Publishing from a branch](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

1. Make the repository Public (GitHub may require account reauthentication).
2. Push these files to `cleanup/dynamic-integration-only`.
3. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**.
4. Select **cleanup/dynamic-integration-only** and **/docs**, then Save.
5. Wait for the Pages deployment to succeed. The tour is at `https://Haipt241.github.io/dynamic-etl-framework/`; the interactive preview is at `/demo/`.

The `.nojekyll` file keeps this buildless. No paid hosting or backend is required for the demo. After merging, change the Pages source to `main` if desired. These URLs become live only after deployment succeeds.
