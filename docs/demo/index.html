Quy trình sử dụng ứng dụng
  1. Khai báo API. Nhập tên integration, URL, endpoint, auth, phân trang, rate limit và mẫu JSON.
  2. Phân tích mẫu. Tool đề xuất cột SQL, làm phẳng object và tạo bảng con cho mảng có ID.
  3. Duyệt schema. Kiểm tra kiểu dữ liệu, khoá chính, nullable và quan hệ bảng con. Thêm endpoint nếu cần.
  4. Duyệt SQL. Xem stage, prod, view, procedure; import template SQL nếu cần. Chưa có thao tác ghi DB ở bước này.
  5. Lưu phiên bản. Xác nhận schema và SQL để lưu cấu hình. Các lần thay đổi tạo phiên bản mới.
  6. Lưu job. Đặt tên job, chọn phiên bản integration, tham số và chu kỳ chạy. Job được lưu để sử dụng lại.
  7. Chạy job. Mở tab Job đã lưu, chọn job để xem chi tiết. Khởi tạo DB nếu cần, sau đó chạy và theo dõi từng worker ở tab giám sát.
  8. Theo dõi và xử lý lỗi. Xem trạng thái, số vòng và log. Dừng job nếu cần. Sau lỗi hoặc dừng giữa chừng, kiểm tra dữ liệu trước khi chạy lại.

INSERT có thể xoá và tạo lại bảng theo SQL đã duyệt. Đóng tab vẫn giữ job chạy; tắt server sẽ dừng job. Reconcile dùng logic runtime hiện có; chưa có màn hình đối soát riêng.

Thiết kế integration

Khai báo API mới hoặc tiếp tục phiên bản đã lưu

Phân tích tài liệu bằng agent

Nhập tài liệu hoặc khai báo thông tin API. Agent đề xuất config kết nối và schema DB riêng biệt để bạn duyệt trước khi lưu.

Đang kiểm tra agent...

Import tài liệu API / dữ liệu raw

OpenAPI/Swagger JSON hoặc YAML, Postman collection, JSON mẫu hoặc tài liệu text có dòng GET URL. Tool đề xuất tên bảng snake_case; bạn duyệt endpoint và mẫu trước khi sinh schema.

Nút agent gửi tài liệu và khai báo tới Claude đã cấu hình. Không nhập secret hoặc dữ liệu nhạy cảm vào tài liệu. Agent chỉ phân tích, không gọi API nguồn hay ghi DB.

Danh sách endpoint
Nhập nhiều dòng: tên endpoint, URL/path, đường dẫn dữ liệu JSON (tuỳ chọn), cách nhau bằng Tab hoặc dấu |. Có thể import JSON chứa danh sách và sample của từng endpoint.





File mẫu đặt theo tên endpoint, ví dụ Orders.json. URL không đủ để suy luận cột; mỗi endpoint cần mẫu JSON. GET, auth và phân trang dùng cấu hình chung bên trên.

    02
    Schema & SQL
    Chưa có schema
    Object được làm phẳng; mảng có ID thành bảng con qua nested_extractions. Mảng chưa có khoá giữ dạng JSON text.
    Chọn PK trực tiếp trên các cột bên dưới. Chọn nhiều cột để tạo khoá chính ghép. PK không được NULL; mẫu dữ liệu không chứng minh tính duy nhất của toàn bộ API.
    Phân tích mẫu hoặc mở phiên bản đã lưu để duyệt cấu trúc.
    

    Cấu hình nâng cao · schema, auth, incremental, reconciliation
    OAuth và auth đặc thù cần cấu hình nâng cao tương thích với runtime. Không nhập secret vào JSON.
    

    Template SQL hỗ trợ Jinja: entities, integration_name, {{generated_sql}}. Sinh SQL để kiểm tra trước khi chạy INSERT.
    SQL preview sẽ xuất hiện ở đây.
